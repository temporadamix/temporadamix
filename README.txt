TEMPORADAMIX — CATÁLOGO WEB NAVIDEÑO 2026

Contenido:
- index.html: página principal.
- styles.css: diseño responsive.
- script.js: filtros, búsqueda, tarjetas y enlaces de WhatsApp.
- products.js: catálogo editable de productos y precios.
- assets/: imágenes del catálogo.

PRECIOS
En los archivos disponibles no encontré una lista legible de precios al detal. Para evitar inventar valores, los productos están configurados con retailPrice: null.

Para cargar precios:
1. Abre products.js.
2. Busca cada producto.
3. Cambia retailPrice:null por el valor, por ejemplo retailPrice:85000.
4. Guarda el archivo.

El sitio calcula automáticamente el precio por mayor como 80% del precio al detal (20% de descuento).
